# SISTEM GENERATOR SOAL UJIAN

Sistem pembuatan Google Formulir ujian otomatis berbasis Google Sheets dan Google Apps Script.

## Fitur

- Penyimpanan bank soal terpusat.
- Mendukung soal pilihan ganda (PG).
- Mendukung soal pilihan ganda kompleks (PGK).
- Mendukung soal menjodohkan (MJ).
- Mendukung soal isian singkat (IS).
- Mendukung soal uraian (UR).
- Import soal dari dokumen Word.
- Pembuatan Google Formulir secara otomatis.
- Pemilihan soal berdasarkan ID.
- Pemilihan soal secara acak.
- Pemilihan soal berdasarkan kriteria mata pelajaran, kelas, materi, dan level kognitif.
- Pengacakan urutan soal.

## Teknologi

- Google Sheets
- Google Apps Script
- Google Forms
- Google Drive API

## Struktur Proyek

- `apps-script/`: kode program Google Apps Script.
- `spreadsheet-template/`: cadangan spreadsheet.
- `dokumentasi/`: panduan penggunaan.

## Catatan

Repository ini digunakan sebagai cadangan dan dokumentasi pengembangan proyek.

Jangan menyimpan kata sandi, token akses, atau data pribadi siswa di repository.
